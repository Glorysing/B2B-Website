## 关于项目

[nantong-plastic.com](https://nantong-plastic.com) 是广东南彤科技有限公司的 B2B 企业官网，面向全球化妆品、个护品牌提供专业的泵阀包装采购与 OEM/ODM 合作渠道。

网站从零开始定制开发——基于 WordPress 定制主题，不使用任何页面构建器，涵盖产品展示、中英双语、在线询盘等核心业务功能，面向 Google 国际 SEO 深度优化，覆盖北美、欧洲、中东、东南亚、日韩等 **20+ 国家**市场。

## 核心功能

| 功能模块 | 说明 |
|:---|:---|
| **中英双语** | 基于 URL 路由切换（`/en/` 前缀），完整的中英翻译体系 |
| **产品数据库** | 119+ 个 SKU，含颈口规格、出液量、材质、MOQ、交期等参数 |
| **智能询盘表单** | 产品页自动预填产品信息，支持最多 10 个附件上传（PDF/图片/文档）|
| **全球足迹地图** | 可视化展示 20+ 出口国家覆盖范围 |
| **资质证书展示** | ISO、SGS、专利等证书专页 |
| **合作品牌墙** | 宝洁、联合利华等头部客户背书 |
| **新闻资讯** | 行业动态与公司新闻 |
| **SEO 优化** | hreflang 标签、结构化数据、服务端渲染产品规格 |
| **性能优化** | LiteSpeed 缓存、JS defer、Cloudflare WAF |
